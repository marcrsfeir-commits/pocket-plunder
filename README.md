# Pocket Plunder

A tiny thief. A pirate ship. A lighthouse gone dark.

A 2D stealth adventure inspired by the iPad classics of the early 2010s. Sneak aboard a pirate ship, steal back the lighthouse's Great Crystal, and sail the ship home.

**Play:** https://marcrsfeir-commits.github.io/pocket-plunder/

## Controls

| Key | Action |
|---|---|
| A / D | Walk |
| W / S | Climb ladders (steer the ship in the finale) |
| E / Space | Hide, grab, search, use |
| H | Hint |
| Esc | Pause |

## Run locally

```
node server.js
```

Then open http://localhost:8795. No build step, no dependencies. Plain HTML5 canvas and ES modules, and all sound is synthesized with WebAudio.
